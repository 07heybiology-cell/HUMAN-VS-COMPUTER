# 🧠 HUMAN VS COMPUTER

## 🎮 Test Your Mind Against the Computer

**HUMAN VS COMPUTER** is an interactive browser-based mini-game that tests different thinking abilities and compares the player's performance with a predefined computer benchmark.

The game contains four different challenges:

- 🧠 Memory
- 🔢 Pattern Recognition
- ⚡ Reaction Time
- 🧩 Logic

At the end of the game, the player's total score is compared with the computer's benchmark score.

---

## 🎯 Project Objective

The main objective of this project is to create an interactive game that tests different cognitive abilities while demonstrating basic web development concepts using HTML, CSS, and JavaScript.

The project demonstrates how JavaScript can be used to handle user input, create interactive challenges, calculate scores, measure reaction time, and dynamically update a webpage.

---

## 🧩 Game Challenges

### 🧠 1. Memory

The player is shown a set of objects for a few seconds.

After the objects are displayed, the player must identify an object that was shown.

**Maximum Score: 10 points**

---

### 🔢 2. Pattern

The player is given number sequences with one missing number.

The player must identify the correct number from the available options.

**Maximum Score: 50 points**

---

### ⚡ 3. Reaction

The player must wait until the reaction box turns green.

The player then clicks as quickly as possible.

The reaction time is measured in milliseconds.

**Maximum Score: 100 points**

---

### 🧩 4. Logic

The player answers simple logical and reasoning questions.

Each correct answer increases the player's score.

**Maximum Score: 50 points**

---

## 📊 Scoring System

| Challenge | Maximum Score |
|-----------|---------------|
| 🧠 Memory | 10 |
| 🔢 Pattern | 50 |
| ⚡ Reaction | 100 |
| 🧩 Logic | 50 |
| **Total** | **210** |

The computer uses a predefined benchmark score of:

**💻 Computer Score: 173 / 210**

The final result shows whether:

- 🎉 HUMAN WINS
- 💻 COMPUTER WINS
- 🤝 IT'S A TIE

## 📈 Performance Analysis

After completing all four rounds, the game displays:

- 👤 Player's total score
- 💻 Computer benchmark score
- 📊 Individual round scores
- 📈 Score bars
- 💪 Strongest area
- 🎯 Area to improve
- 🔢 Difference between human and computer score

This helps the player understand their performance across different challenges.
